# Portfólio de Algoritmos e Lógica de Programação em Python

Projeto acadêmico desenvolvido no **1º semestre de Ciência da Computação na Unisagrado, em 2025**, reunindo exercícios e desafios implementados em **Python** e **pseudocódigo**.

O objetivo deste repositório é registrar minha evolução na resolução de problemas, construção de algoritmos e aplicação prática de conceitos fundamentais de programação.

## 📚 Conteúdos trabalhados

Ao longo das atividades, foram praticados conceitos como:

- Entrada e saída de dados
- Variáveis e operadores
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`for` e `while`)
- Operadores lógicos e relacionais
- Acumuladores e contadores
- Validação e comparação de dados
- Resolução de problemas com algoritmos
- Representação de soluções em pseudocódigo

## 💻 Exemplos de exercícios

Entre os exercícios desenvolvidos estão:

- Cálculo de médias e situação de alunos
- Cálculo de prestações e descontos
- Comparação entre datas
- Verificação de ano bissexto
- Controle de estoque
- Processamento de notas de uma turma
- Simulador de caixa eletrônico
- Inspeção de qualidade
- Análise pluviométrica
- Simulação de investimento
- Pesquisa de satisfação
- Caixa registradora
- Crescimento populacional
- Cálculo de consumo de energia
